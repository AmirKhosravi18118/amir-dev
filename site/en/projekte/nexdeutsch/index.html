NexDeutsch

Learning German needs planned repetition so vocabulary sticks.

View live Open gallery Request similar

The project

NexDeutsch helps people learn German vocabulary with spaced practice. Words come back just before you would forget them, in short daily sessions organised in courses from A1.

What it does

  • Offers courses by level, starting at A1
  • Repeats words with a Leitner box system
  • Shows example sentences with meanings
  • Works in several interface languages

How it looks

A light, uncluttered interface with soft green and lilac tones. Each word sits on a large card, and a progress bar shows how far the session is.

Solution
A vocabulary trainer with spaced repetition, full example sentences and a Persian interface.
